# `ext-remote-config`

Remote monetization & partner offer configuration synced by all 210 browser extensions across `maxwork/`.

## Quick Push to GitHub (`main`)

```bash
cd "github_remote_repo"
git init
git branch -M main
git add config.json README.md
git commit -m "chore: live Dodo $7.44 + XM $30 Bonus config"
git remote add origin https://github.com/firstbabyreborn-ai/ext-remote-config.git
git push -u origin main
```

Once pushed, raw config URL is:
`https://raw.githubusercontent.com/firstbabyreborn-ai/ext-remote-config/main/config.json`
